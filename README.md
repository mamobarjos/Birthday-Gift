# 🎁 بطاقة عيد ميلاد تفاعلية وثلاثية الأبعاد | Interactive 3D Birthday Gift Card

> **تجربة ويب احترافية ومبهرة لتقديم تهنئة عيد ميلاد بأسلوب سينمائي مبتكر، تدمج بين تأثيرات المصفوفة (Matrix Rain)، وجسيمات النصوص المتفجرة (Particle Text)، وكتاب ذكريات واقعي وثلاثي الأبعاد (3D Memory Book) مع مشغل موسيقى ذكي وتصميم زجاجي فاخر.**

---

## ✨ المميزات الرئيسية (Key Features)

| الميزة | الوصف |
| :--- | :--- |
| 🌧️ **خلفية المصفوفة المطرية<br>(Matrix Grid Engine)** | مطر أحرف رقمي متساقط بألوان وردية متدرجة (`#ff2d75` و `#ff77a5`) مع تأثيرات توهج وحركة هادئة وأنيقة. |
| 🎆 **جسيمات النصوص والقلوب<br>(Particle Text Engine)** | عد تنازلي وتفجير سينمائي لكلمات التهنئة ورسم قلب ثلاثي الأبعاد بالجسيمات المتوهجة، مع دعم كامل للغات (العربية والإنجليزية) والأسطر المتعددة. |
| 📖 **كتاب ذكريات ثلاثي الأبعاد<br>(3D Realistic Memory Book)** | محاكاة فيزيائية واقعية لغلاف الكتاب وصفحاته، تشمل إظهار سمك الأوراق، والظلال الواقعية، وتقليب الصفحات بسلاسة باللمس أو النقر، مع حركة القط العازف في خلفية المشهد. |
| 🎵 **مشغل موسيقى زجاجي منبثق<br>(Modern Glass Audio Bar)** | شريط تحكم بتصميم زجاجي راقٍ (Glassmorphism) يحتوي على زر كتم ومؤشر سحب منبثق (Pop-out Slider) بتعبئة لونية ديناميكية وتوقيت ذكي يبدأ الموسيقى بعد العد التنازلي ويخفتها تدريجياً في نهاية العرض. |
| 📱 **متجاوب وسلس بالكامل<br>(Fully Responsive & Touch Ready)** | أداء فائق وسرعة استجابة على جميع أجهزة الكمبيوتر والهواتف الذكية والأجهزة اللوحية مع دعم إيماءات اللمس. |

## 🚀 طريقة التشغيل والاستخدام (How to Run)

المشروع مبني بالكامل باستخدام التكنولوجيا الأساسية للويب (Vanilla HTML5, CSS3, & JavaScript Canvas API) ولا يحتاج إلى تثبيت أي مكتبات أو أدوات معقدة!

1. **التحميل أو النسخ (Clone)**:
   ```bash
   git clone https://github.com/mamobarjos/BirthdayGift.git
   ```
2. **التشغيل المباشر**:
   - قم بفتح ملف `index.html` مباشرة في أي متصفح حديث (Google Chrome, Safari, Microsoft Edge, Mozilla Firefox).
3. **التفاعل مع العرض**:
   - انقر أو المس الشاشة في أي مكان لبدء العد التنازلي والموسيقى.
   - عند ظهور كتاب الذكريات، انقر على الغلاف أو الصفحات لتقليبها واستعراض الرسائل والصور.
   - استخدم شريط الصوت العُلوي للتحكم بمستوى الصوت أو كتمه في أي وقت.
   - يمكنك إعادة تشغيل العرض كاملاً من خلال زر **"↺ إعادة التشغيل"** في نهاية العرض.

## 🛠️ التقنيات المستخدمة (Technologies Used)

- **HTML5 Canvas**: لرسم الجسيمات ومصفوفة الخلفية وكتاب الذكريات بأداء عالي (60 FPS).
- **Vanilla JavaScript (ES6+)**: لبرمجة المحركات الفيزيائية وإدارة التوقيت والتفاعل دون أي مكتبات خارجية.
- **Modern CSS3 / Glassmorphism**: لتصميم عناصر واجهة المستخدم بتأثيرات زجاجية وتوهجات ناعمة.
- **Web Audio API & HTML5 Audio**: لإدارة الموسيقى والتحكم بالتدرج الصوتي (Fade-out/Fade-in).

## 📝 ملاحظات للمطورين (Developer Notes)

- **تعديل النصوص والكلمات**: يمكنك تخصيص كلمات العد أو رسالة التهنئة مباشرة من مصفوفة `WORDS` ومصفوفة `BOOK_SPREADS` داخل ملف `index.html`.
- **تخصيص الألوان**: يتم التحكم بالألوان الأساسية للجسيمات والخلفية عبر المتغيرين `THEME_COLOR` (`#ff2d75`) و `THEME_COLOR2` (`#ff77a5`) في `index.html`.
- **الوسائط والصور**: لاستبدال صور الكتاب أو غلافه، فقط استبدل الملفات الموجودة في مسار `Assest/Book/Love/` مع الحفاظ على نفس أسماء ومقاسات الملفات لضمان أفضل عرض.
